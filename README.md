## 👨‍💻 About Me

I build tools inside the Roblox ecosystem — from custom UI libraries with smooth, professional-grade animations to backend systems that hold entire script hubs together. My focus is on writing code that's clean, modular, and built to scale, not just "good enough to ship."

Right now I'm building **LuXy Hub**, and heavily exploring AI-assisted development workflows — designing structured prompts and agent configurations to get more precise, production-ready output from AI coding tools.

- 🔭 Currently working on **LuXy Hub** — a Roblox script hub ecosystem with a custom UI library and companion website
- 🎨 Deep focus on **UI/UX for Roblox** — animation timing, easing curves, theming systems
- 🔍 Interested in **reverse engineering** and how things work under the hood
- 💬 Ask me about **Luau UI systems**, **Roblox scripting**, or **AI-assisted dev workflows**
